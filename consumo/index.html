Origem do número. Dados ao vivo da mesma API usada pelas páginas Rastreador e Utilities (função ntn-lab), atualizados a cada 45 s, sem cache. Os bytes são o tamanho do payload de cada mensagem recebida pelo servidor (campo bytes). Isso é uma estimativa: não inclui cabeçalhos de rede, TLS, retransmissões, registro na rede nem mensagens perdidas. O valor cobrado é o medido pela operadora. Limite da API: o rastreador devolve no máximo os últimos 14 dias e o medidor os últimos 62 dias, sempre contados a partir de hoje (a API não aceita data de início). Períodos fora dessa janela aparecem incompletos ou como "sem dados". A API não informa o ICCID; cada chip é identificado pelo dispositivo em que está instalado. Sem mensagens no mês, o chip aparece como "sem dados".
